- 7컷/60초 Studio 실험과 **장편 v0.2 약 18,258자**는 같은 최종 승인 원고가 아니다. 단편 실험 합격/렌더 가능을 장편 제작 승인으로 대체 금지.

## 우선 실행 명령 — 추가 영상 생성보다 내부 결함 해결
1. 사용자에게 이미 좋은 반응을 얻은 프롤로그/1막의 **관점과 거리감은 보호**하되 내용별 사료팩(확실한 사실/해석/미상/영상 재현) 작성.
2. 한 장면의 훅이 아니라 **전체 6막의 비트-사실-새 발견-갈등-결말 회수 지도**를 작성하고 중후반 반복을 직접 삭제/재작성한 v0.3 후보(원본 별도 보존).
3. 모르는 관객의 0~30초 질문, 막별 서사 정합, 원전/경쟁 전편 대비를 Council이 작품 사전 검수. 의견만 기록하고 실제 문장 미수정이면 미해결.
4. [시각 서사 스킬](../skills/CULTURAL_VISUAL_DRAMATURGY_SKILL_V1.md)에 따라 최초 60초 모든 컷의 `새 시각 정보 / 원본 부분 / 서사 목적 / 실제 사용권 / 근거`를 먼저 내부 감수. 의미 없는 반복을 제거한 쇼트 계약을 승인하기 전 이미지 생성/렌더 금지. 각 쇼트가 실제로 서로 다른 시각 사건을 보여주는지는 접촉시트·실제 컷 리뷰 전에는 NOT_VERIFIED.
5. 실제 원문이 통과한 뒤에만 저작권/해상도 확인 진본 사용, 3~5분 파일럿·한국어 무음악 낭독, 이후 필요 자산 생성.
5. 독립 외부 Gemini는 **고정된 내부 버전의 문제만 감사**, 수정 권한 없음. 외부 지적은 내부 원인으로 되돌리고 원문/스킬 수정.

**금지:** 세한도 v0.1/v0.2를 95점으로 간주, mock 점수, 단순 다크→브라이트/모델 교체를 작품성 해결책으로 주장, 유사 원화 생성/사료 날조, 무한 제안 반복, 외부 LLM에 작품 전체 재구성 위임.
