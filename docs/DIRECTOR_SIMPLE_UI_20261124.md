# GPT형 Director 단일 화면 (2026-11-24)

경로: \`http://127.0.0.1:8080/studio/simple/\`

## 목적 및 현재 검증 경계

기존 Murim \`/studio/\`의 M-VML 불변 리비전, 00A/00B/00C 시나리오 편집·독립 심사·인간 승인, 안전한 실제 에셋 등록, 수동 ComfyUI 연결 및 FFmpeg 렌더를 재사용한다. 새 화면은 제품을 다시 만드는 대신 감독용 프롬프트 UI를 제공한다.

사용자의 개입은 원칙상 **시나리오 감수**와 **주인공·등장인물·화풍·장면별 스토리보드 선정**이다. 모델·워크플로 검증 전에는 요청/결과 전달을 사람이 중계할 수 있다. 승인 전 렌더 및 미디어 자동 합격을 금지한다.

### 현 단계 실제 기능

1. 작품 **생성/조회/이름 변경/보관/보관 해제**. 보관은 파일 삭제가 아닌 가역적인 상태 기록이며, 원본 MVML·미디어·리비전은 보존.
2. 기존 \`/studio/\` 사전 제작 기능을 대화상자로 열어 동일 작품의 시나리오 원문 비교·재심사·명시 승인. 본질적 G1/G2 승인 기준을 약화하지 않음.
3. 승인된 시나리오를 GPT에 전달하기 위한 사람매개 이미지 제작 프롬프트, GPT 생성 이미지의 사용자 업로드, 출처/사용권 기록.
4. 이미지 후보를 **주인공/화풍/소품/장소/장면별 스토리보드**로 분류하고 선택 변경. 별도 director 리비전이 SHA-256 연결된 JSON 스냅샷으로 저장됨.
5. **필수 캐릭터·화풍·모든 장면 이미지**를 선택해 사람 명시 확정 시 실제 M-VML 이미지 트랙에 asset ID를 결속; 장면과 심사 승인 상호 일치 검증. 나중에 기존 시나리오 승인이 철회되면 제작 자격도 상실.
6. 장면별 동작·키프레임 **사람매개 요청 프롬프트**, 검증 전 실제 외부/ComfyUI 렌더 결과의 **등록**, 기존 Studio의 실제 렌더/영상 후보를 입력 이미지 갤러리와 분리 재생. 생성되지 않은 영상이나 자동화는 성공으로 표시하지 않음.

### 아직 검증되지 않아 자동 실행을 막은 기능

- GPT의 이미지 생성 API 직접 호출과 무인 이미지 생성. GPT 채팅에서 후보를 만들고 사용자가 선정해 등록하는 원칙에 따라 초기 단계에서 필수가 아님.
- ComfyUI가 GPT 수준의 참조 이미지, 캐릭터시트, 고난도 움직임 키프레임을 프롬프트만으로 대량 생성할 수 있는지 품질 검증.
- 현재 등록된 LTX 원저자 워크플로의 **다중 이미지 시간 배치 API 그래프**, 이미지 3~N장 \`insert_frame_N/strength_N\` 자동 결속, Preview/Final 출력의 일관성 및 GPU 실측.
- **자동 품질 평가·실패 샷 재시도·최종 편집**을 무인으로 종결하는 신뢰 가능한 루프.

위 항목들은 고급 Studio의 검증된 실행 기능과 다르므로 단순히 자동화 완료라고 주장하지 않는다. 특히 현재 기존 \`src/studio/comfy.py\`는 등록 그래프에 **단일 장면 이미지 1장**을 바인딩하는 방식이며 다중 키프레임 자동 연결로 오인하면 안 된다.

## 운영 순서

1. 새 작품 생성 → Director 프롬프트로 초안/수정안 준비 → 같은 화면의 기존 Studio 감수 대화상자에서 시나리오 정식 승인.
2. GPT가 제작한 주인공·화풍·장면별 이미지 후보 등록(출처 및 실제 권리) → 사용자 선택/교체 → 스토리보드 확정. 내부 등록은 기존 \`/studio/api/project/<pid>/asset\` 사용.
3. M-VML 장면 트랙의 승인된 에셋 ID를 기준으로 동작 지시문 생성. 실증 전에는 사람매개 요청/결과 등록; 실제 영상 후보는 품질 PASS가 아닌 **CANDIDATE_REQUIRES_VIEWING**으로 표시.
4. 기존 \`/studio/\`에서 신뢰된 ComfyUI API graph / 실제 GPU 출력/FFmpeg/독립 사용자 영상 심사 진행. 이후 충분한 실증을 거쳐서만 단일 화면 자동 버튼 활성화.

## 안전과 저장소 계약

- \`hoonoh57/murim\` GitHub가 개발 원본; Windows \`E:\gpt\projects\comfyui\murim\`은 실행 소비 클론. Windows 사용자 staged/unstaged/untracked/ignored 원본 파일, 인증정보/미디어 원본/워크플로 보호.
