# Local-First Story Documentary Factory — 콘텐츠 사업 방향 전환안

> 작성: 2026-11-21 (KST) | 대상: `hoonoh57/murim` | 성격: **제작·시청 지표 실증 전 전략 설계**, 실질 GPU 렌더/영상 게시 성공 아님.

## 1. 사업 가설과 전환 이유

기존 `SCAIL-2` 2초 검술 전이 시연은 학습용 기술 성과이지만, 연속 무술 동작 및 실사형 20~30초 상업 영상의 품질을 입증하지 못했다. 검술 driving source 개별 수집은 콘텐츠 자동 생산의 병목이다. 새 우선 가설은 **사실·스토리·내레이션 중심의 오리지널 롱폼**에 독창적으로 기획된 고품질 이미지, 심플한 카메라 움직임, 적정량의 짧은 영상 클립, 자막·음향·음성 연출을 결합하는 것이다.

사용자 제공 유튜브 스크린샷: `숨겨진 동양사 — 인물편` 약 54분 영상, 화면상 약 1개월/40만 조회 표시. 이는 **사용자 스크린샷 관찰**일 뿐 제작 기술, 실제 시청 지속시간, 수익, YPP 여부의 증거가 아니다. 경쟁작에 대응하기 위해 증거 없이 생성 모델을 추측하거나 조회수=수익으로 계산하지 않는다.

## 2. 공통 제작 코어 / 상이한 주제 정책

| 시리즈 | 강점 | 출처 및 정책 | 권장 편성 |
| --- | --- | --- | --- |
| 명작의 향기 | 작품 해설, 작가의 삶, 인간 감정 | 공공영역 여부와 **번역문·삽화·공연/영상의 별도 저작권**을 각각 확인. 원문 대량 낭독 지양 | 내러티브/해설 |
| 인류의 숨겨진 비사 | 역사 인물, 제도, 권력 갈등, 반전 | 1차/2차 사료로 사건·날짜 교차확인; 논쟁적 추정은 추정이라 표시; 생성 인물·사건 재현 화면에 표시 | 내러티브/다큐 |
| 주식고수열전 | 투자자의 결정과 성공·실패, 역사적 시장 | 1차 기록·금융 데이터 확인, 편향/생존자 편향, 재현할 수 없는 수익 주장 주의; 개인 맞춤 투자 지시·확정 수익 금지 | 금융 역사/심리 |
| 성지·명작·명화 순례 | 유산, 작가, 장소의 시각적 몰입 | 이미지와 촬영 원본 권리, 박물관 사진의 별도 이용 조건, 교단·유적에 대한 정확한 해설 | 에세이/다큐 |

모든 분야에서 **관심 제목과 썸네일이 실제 내용과 일치**해야 한다. 유료 외부 API를 전제하지 않음. 로컬 오픈소스 TTS/이미지/편집기 모델 선택 및 현 Windows 실행은 실제 검증 후 결정한다.

## 3. 기존 Murim 4-GATE를 재사용한 생산 공정

| 게이트 | 책임 | 입출력·완료 조건 |
| --- | --- | --- |
| G1: Topic / Script | Writer + Council + Director | 주제 후보, 타깃 시청자, 검증된 참고 출처, 원고 원본, 주장별 증거, 후킹/갈등/결말 포함 시나리오; 원작 표절 및 허위정보 거부 |
| G2: Art / Edit Plan | Art Direction + Camera + Director | 샷 단위 scene manifest: 대사·화면·키워드·감정·색·이미지/지도·움직임·시간·사용권·적합한 자막; 16:9 기본 |
| G3: Local Production | Imaging + Audio + Video | 저작권 정리된 생성 이미지, 한국어 자연스러운 음성·발음, 자막 타임코드, FFmpeg 컷/줌/팬/전환, BGM/SFX, 인물·배경 일관성. 움직임 필요한 곳에만 짧은 클립; 영상 생성 모델 호출 **선택 사항** |
| G4: QA / Release | Director + Marketing + 사람 승인 | 사실 검증표, 이미지 사용권 기록, 샷/오디오 싱크, 소리 크기, 자막, 썸네일·제목·설명 출처, 정책 체크. 사람 승인 전 **외부 게시 금지** |

**공통 프로덕션 객체:** `episode_id, series_id, audience, topic, claim_sources[], rights_manifest[], script_sections[], scenes[], voice_timing[], images[], clips[], subtitle_segments[], thumbnail_variants[], qa_results[], release_status`를 구조화한다. 현재 구현 완료된 API라고 주장하지 않으며, 향후 데이터 계약 설계 항목이다.

- https://support.google.com/youtube/blog/356734251/response-to-creator-questions-about-ypp-policies-july-2025 — 내레이션·이미지 생성 AI 도구 사용은 곧바로 수익화 금지 사유가 아니나, 반복적 스토리나 서술과 부족한 차별성이 문제다.
- https://support.google.com/youtube/answer/2797466 — 퍼블릭 도메인/저작권 판단은 원저작물별 검증 필요.

기획마다 **자체 리서치와 새 대본, 독자적 해석**을 의무화한다. 책 요약 복제, 타인 영상/이미지 무단 재업로드, 사실과 생성 재현 혼동, 사용권 확인 없는 음원/지도/사진 사용을 금지한다. 창작자/AI 재현 표기와 필요 공개 기준 적용.

## 5. '하나의 엔진, 여러 채널' 운영 원칙

1. 장르 혼합이 구독자 기대와 추천 피드에 미치는 영향은 실제 분석 전 **UNKNOWN**. 서로 다른 관심층(주식 vs 종교/고전)을 초기 한 채널에 무작정 혼합하지 않는다.
2. MVP는 **한 시리즈** `인류의 숨겨진 비사` (시청자 반응에 따라 변경 가능)로 시작. 한 편당 8~12분, 16:9, 정지·가벼운 카메라 무빙 중심, 0~2개의 짧은 영상 강조 컷(필수 아님).
3. 첫 한 편: 실제 공개 출처 3개 이상으로 근거를 교차확인할 수 있는 역사적 인물 한 명을 골라 원고→이미지→한국어 내레이션→자막→편집→최종 영상까지 **로컬에서 끝까지 실행**. 초기 숫자는 작업량 설계치이지 알고리즘 최적점 아님.
4. 첫 **4주 가설 검증**: 품질 기준을 통과할 때만 주당 1편 롱폼 + 해당 에피소드에서 1~2편 쇼츠 발췌를 목표. 실제 자동 예약·업로드 기능은 아직 NOT_VERIFIED; 사람 승인 후 게시.
5. 성과 측정: 인상수, CTR, 초반 30초 유지율, 평균 시청 지속시간, 완주율, 구독 전환, 영상당 제작시간, 자산 재사용률, 저작권 클레임, 시리즈 간 반응 차이. 수익 숫자나 조회수 보장 금지.
6. 원칙: **콘텐츠 완성도 우선, 자동화는 반복 가능한 작업만**. 성과가 미달하면 먼저 훅·원고·내레이션·편집과 정보 정확도를 개선한다. 무작정 영상 모델 추가/스텝 상향 금지.

## 6. 로컬 역량 검증 범위

- 기존 환경: RTX 4070 Laptop 8GB, 32GB RAM, `E:\ComfyUI_New` 보존, 분리된 `E:\comfyui-scail`. 해당 장비에서 8~12분짜리 완성 영상 제작 자동화의 처리시간·품질은 **아직 검증되지 않음**.
- 이미지/음성 합성/영상 컷 편집은 GPU/CPU 사용 분리가 가능하나 TTS 한국어 발음, GPU 메모리, 렌더 시간, 로컬 디스크, 배경음 사용권은 실측 필요.
- 기존 `SCAIL2_FULL_00001` 성공, 사용자 LTX 한국어 대사 사례는 보존. 신규 사업 MVP에서 검술 동작 생성은 **필수 게이트가 아님**.
- 소스 제어는 GitHub `hoonoh57/murim`, Windows는 안전한 동기화/소비 환경. 현재 새 콘텐츠 MVP의 end-to-end 실제 영상은 **NOT_RUN**, 새 기능 BUILD/TEST도 **NOT_RUN**.
