## 3. 초기 시장 언어 관측 — 사실과 가설 구분
W001–W003의 공개 제목·장르 표기에서 선협/퓨전/현대판타지의 조합과 구체적 능력/갈등 해결을 예고하는 표현이 관측된다. 이는 제한된 상위 제목 표본에서 관찰된 언어이지 장르 전체의 트렌드나 흥행 원인이라는 증거가 아니다. 가설: 제목이 제공하는 선명한 독자 약속과 실제 첫 회차 보상의 일치가 진입 후 몰입에 기여할 수 있다. 중·하위 동일 제목 전략 사례, 실제 원고·독자 데이터, 노출 통제 비교가 필요하다. 제목/작품 고유 설정 복제 금지.

## 4. 분석 기록 작성의 최초 수용 기준
실제 판본/열람 권리/관측 범위 → 전편 감상 → 장면/회차/beat 및 근거 위치 → 강·약·특이·감정 가설 → 실제 관객 증거 → 대조/반례 → 일반화 원리 및 적용 조건. 미확인 항목 NOT_OBSERVED. 정성 기록의 평가자/검증 분리. 현재 모든 후보는 작가용 검증 pattern 승격 불가. 원천 목록 10건은 실제 분석 10건이 아니다.
