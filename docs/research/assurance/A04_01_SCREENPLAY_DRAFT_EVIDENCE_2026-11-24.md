## 2. 실제 작성 및 내부 분석

공통 생성 목표: 도윤의 숨긴 본명과 통행 보증이라는 대립을 직접 선택으로 해결. A는 선명한 갈등·대사와 결말, B는 처음부터 장부/빈 보증인 칸/마감 종을 시각 단서로 사용하고 결말의 장부 공개 행동을 강조. B의 전문 지식은 Q2의 원저자 제작 기록 B02~B05에서 추출한 미검증 원리 후보(불필요한 장면 제거, 제작 제약 선반영, 원본 revision 보존). Spring의 서사·인물·장면을 차용하지 않음. 원리의 인과적 효과는 미검증. 실제 전문 원고 비교/지식 기여도는 A02 미달과 연결.

사후 작성자 state trace (runtime trace 아님):
- 시작: 도윤=가명으로 숨어 있음, 소연=약상자 소지, 문=닫힘, 종=아직 미발생, 장부=본명 보증 필요.
- 갈등: 소연의 목적=적대 문파에 약 전달; 도윤은 보증인 본명 공개와 추적 위험을 인식. 소연은 위험을 이해하고 강요하지 않음.
- 선택: 도윤이 장부에 백무진을 기록; 스스로 문을 열어 소연이 통과. 새로운 사람/장치로 해결하지 않음.
- 결말: 마지막 종 뒤 문을 닫고 기록을 남김. 약 전달 완료/환자 회복/추적 실제 발생은 화면 밖 미확인.

고정 brief의 H1~H7은 작성자 원문 검토 범위:
| H | A r1 및 B r1/r2 관측 | 한계 |
|---|---|---|
| H1 | 실제 행동·대사·선택·결말, 끝 표기 | 완결 여부의 전문 수용 미검증 |
| H2 | 장면 제목 1개, 도윤/소연 2인 대사 및 행동 | 영상 실물 없음 |
| H3 | 청령문 환자 약 전달 목적, 마지막 종 마감 | 실제 관객 이해 미측정 |
| H4 | 본명 보증 규칙과 추적 위험 대사 | 제도는 허구; 역사 사실 주장 아님 |
| H5 | 백무진 기록→문 개방→소연 통과 | 연출/실제 동작 미검증 |
| H6 | 추가 인물/전투/초자연 해결 없음 | 영상 기술 검증 아님 |
| H7 | 새 연구용 허구, 실제 인물/사료 주장 없음 | 독립 유사성/권리 심사 미실행 |
| H8 | 실제 낭독 및 animatic 시간 NOT_RUN | 60~90초 목표 충족 미확인, HOLD |

## 3. 표적 수정 실제 증거

B r1 자체 검토: 추적 위험 대사의 장황함, "어르신까지 잃을 수는 없어요"가 전사 관계를 과도하게 암시, 약상자에 이름을 묻는 대화가 주제 설명용처럼 보임, 결말의 주제 재설명. 대사 5줄만 수정. 도윤의 가명/추적 설명 명료화, 소연이 본명 기록을 만류, 환자가 소연의 문파를 아는지 묻는 자연스러운 선택 전환, 마지막 대사를 "가라."로 축소. 새 사건/인물/소품 추가 없음. 기존 행동 지문 전수 보존 확인. 수정 전/후 대사 줄 수 동일.

실제 JS 문자열 검사 (Unicode code points, 파일 전체 글자 수는 제목/메타/공백/LF 포함; 대사 본문은 화자 접두사와 LF 제외):
| | 전체 글자 수 | 대사 줄 수 | 대사 본문 글자 수 | 장면 제목 수 |
|---|---:|---:|---:|---:|
| A r1 | 666 | 11 | 251 | 1 |
| B r1 | 675 | 11 | 237 | 1 |
| B r2 | 652 | 11 | 211 | 1 |

B r1→r2: 표제 1줄/대사 5줄 치환, 비대사 행동 줄 동일. 대사 26자 감소(약 11%). 대사 감소를 품질 향상이나 상영시간 단축 실측으로 해석하지 않음. 전문 평가/관객 이해/감동/독창성/한국어 낭독/동일 예산 비교/실제 경쟁 앱/봉인 holdout NOT_RUN. 본 실증은 창작 산출물과 국소 변경의 직접 증거에 한정.

## 4. A04 심사와 다음

실제 전체 원고 생성과 표적 수정 가능성에 대한 제한된 직접 증거 확보. A04 전체 NOT_QUALIFIED: 독립 전문가/관객 및 평가자 보정, 강한 동등 조건 비교, 실제 시장/작가 지식 효과, 낭독·시간·시각화 미확보. ENVIRONMENT_ISSUE(독립 평가 접근 및 실제 영상 환경 미확보), TEST_DESIGN_LIMITATION(순차 같은 생성자, A context 오염 가능, 동등 비용/시간/블라인드 미확보). 전자는 기존 분류, 후자는 실험 한계로 기술(제품 결함 아님). 다음 A05는 이 고정 B r2를 연구용 원고 입력으로만 사용해 shot/scene 양방향 추적, 시선/화면 방향/동선/시간/소품·정보 continuity 및 실제 정지 프리비즈 가능 범위 검토. A04가 승인되었다고 간주하지 않으며 시각 산출물/낭독·평가를 실제 확보하지 못하면 HOLD. 전체 제품 코드 동결 및 Q1~Q4 재개 조건 유지. 신규 제품/테스트 구현, Windows, 설치, 유료 호출, 게시, 승인 없는 외부 전송 없음.
