### 합성·색상·자막
CompositingPlan: ordered layers, input alpha interpretation straight/premultiplied, mask ranges/transforms, aspect/safe area/crop/pad, z-order, blend/effect graph, color metadata/working/output space, OCIO/LUT config digest, grain/grade and temporal scope. 원본 생성물 수정 없이 layer/effect로 편집. 정확한 글자/서명은 필요 시 별도 overlay 후보, tracking·occlusion·perspective·source coverage 검증; 화면 속 잘못된 원문 문자가 남아 겹치면 불합격. unknown color/alpha profile은 검사 후 HOLD 또는 승인된 해석, 임의 HDR→SDR/색공간 tag 변경 금지. preview display transform과 final output transform 구분, double tone mapping 방지. FFmpeg/OCIO adapter는 capability/actual config를 검증; 복잡한 node 합성은 검증된 외부 compositor 후보, 무단 전용 shell 기능 금지.

### 편집 교환·렌더·복구
Canonical JSON aggregate는 목표 SSOT; 기존 M-VML 현재 권위 유지. Import는 isolated candidate+semantic diff, asset mapping 및 승인 CAS; 기존 revision 보존, conflict 명시 반환. Export→import semantic equivalence 검증(파일 바이트 동일만으로 평가하지 않음), 실제 NLE 재생/렌더 대조. 신규 XML→JSON migration 또는 UI 코드 변경 현재 금지.
RenderManifest: pinned input digests, ordered operations & dependency graph, render engine binary/build/filter/config/font/LUT/recipe/profile digests, output range & frame/sample counts, codec/bit depth/pixel format/channel layout/metadata, resource and actual job/attempt evidence. proxy/preview 원본 mapping 명시, final은 승인된 원본으로 resolve. 실제 frame/PTS/sample/codec/색상/자막/오디오 stream probe, 전체 decode, visual check. 품질 증거는 실제 최종 출력 digest에 결속. cache key에 영향 입력/효과/엔진/색상/폰트/시간 mapping 포함, content-addressed immutable intermediate. non-deterministic encoder은 byte-identical 재생성 보장 금지; reference and decoded equivalence/허용 편차를 시험 전 정의.
