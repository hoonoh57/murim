# 기존 5개 후보 선행 시장 screening — 2026-11-24

기준 HEAD 67db10e990c504bbc3175351dac5b18b00f42d42. [신규 시장 선행 게이트](../../MURIM_PREPRODUCTION_MARKET_GATE.md).
실제 기존 후보 문서의 제출 증거와 현재 공개 수익화 정책을 검토했다. 생산/시장 데이터 실측과 구분. 모든 현재 제출 후보를 qualified pool에서 제외하며 순위를 폐기한다. 장르 자체의 경제성 최종 판정은 아니다.

## 관측한 실제 반증
- 문피아 일반 FAQ https://nhelp.munpia.com/faq?page=14 에서 직접 AI 생성 본문·표지 불허 확인. 따라서 Murim 자동 생성 원고를 그대로 올려 직접 유료화하는 경로는 REJECTED_POLICY. 공개 구매 순위는 장르 탐색 신호로만 사용할 수 있고 숏드라마·영상 수익성을 증명하지 않는다.
- YouTube YPP https://support.google.com/youtube/answer/72851 및 Shorts 수익화 https://support.google.com/youtube/answer/12504220 에 따르면 광고 수익에는 자격 및 해당 모듈 수락이 필요하며 수락 이전 Shorts 조회는 수익 배분 대상이 아니다. 기존 5개 후보의 실제 YPP/모듈 자격 증거 없음. 해당 광고 매출을 지금 발생한다고 가정하는 모델은 제외. 2027 정책 변경 가능성도 수익 예측 H에 반영하기 위해 원문/지역/적용일 재확인. 공식 공개 검색 발췌에는 2027-02-01 이후 요건 변경이 표시되나 해당 언어 페이지 직접 열람 cache miss, 적용 확정으로 처리하지 않음.
- 공개 조회와 유효 수익 조회는 정의가 다르며 타 채널 실제 수익·유지율·YPP 여부를 공개 조회만으로 추정 확정 불가. API 정책상 데이터 보관/파생지표 허가 확인 필요. 공식 YPP 및 공개 조회 API, 정책은 평가 게이트 문서 참조.
- 기존 M01~M08의 설치/플랫폼 인앱매출/Netflix 시청/한류 수요/문피아 순위 등은 소재 연구 신호. 제출 증거 중 후보별 실제 정산/비용 또는 동일 규모 신규 제작자의 성공/실패 분포, 강한 concept 대조 평가, 해당 난제의 합격 비용 실측이 0건. 따라서 시장 우위/수익성 증명의 자료로 사용 불가.

## 판정 규칙의 수동 산식 점검 (전부 가상 fixture, 시장 추정 아님)
정책 후보 r=20%, H=90일, 통화 KRW, 단일 광고 경로, C=200,000원, 실제 수취 RPM=100원이라는 가정.
- 필요한 유효 수익 조회 2,400,000 = 1000*200,000*1.2/100. 손익분기 2,000,000. 공개 조회 아닌 자격 취득 후 수익 정의에 맞는 조회.
- 실현 가능한 상한이 300,000이면 상한 수취 30,000원, 손실 170,000원, 목표 미달 REJECTED_ECONOMIC_INFEASIBLE. 높은 인기/점수로 상쇄 금지.
- 기존 비용 200,000 대신 검증된 비용 상한 20,000으로 변경하고 보수적 유효 조회 하한 300,000 및 RPM 하한 100원이라면 수취 하한 30,000원, 순기여 하한 10,000원, ROI 하한 50%: 경제 산식 조건만 통과(24,000원 이상). 실제 전체 M1~M6 및 품질·권리/시간/예산 검증 전 생산 승인 금지.
- 광고 자격 미충족/모듈 미수락으로 해당 기간 수익 0이라면 어떤 조회 숫자도 광고 매출로 인정하지 않고 해당 단일 경로 실패. 계약·정산/RPM 근거 없음이면 분모/수익 모델 미확정으로 제외.
- 평균 수익이 높아도 보수적 하방 조건 실패→재설계; 성공작만 포함한 코호트/시간 누출/가짜 독자→M2/M6 탈락.
위는 선언형 설계 산식의 수동 예시이며 실제 market evaluation engine 테스트, 실제 데이터/예측 검증, 사용자 장비 품질·원가 또는 시장 성공률의 증거가 아니다.
