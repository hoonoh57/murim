# 《세한도》 첫 서사 — 최상위 내부 심사 계약 v1

**목표:** 세상에 없던 장르를 선언하기 전에, 같은 원고를 **역사적 정확성, 지적·정서적 깊이, 시청자 체험** 세 층위에서 거부할 수 있는 엄격한 작업 절차 수립. 대본이 만들어졌다고 영상화하지 않는다.

## 핵심 차별화
- 일반 해설은 '김정희가 어려울 때 변함없는 이상적에게 고마움을 표했다'로 마무리될 수 있다.
- 본 초안의 명제는 **이상적이 변하지 않은 것보다, 추사가 그것을 알아보게 된 계절과 그 후 수백 년을 이어 온 기록**이다. 마지막 질문을 '내게 남아 준 사람은?'에서 '나는 누구에게 같은 사람인가?'로 전환한다.
- 이것이 독창적 표현을 곧바로 입증하는 것은 아니다. 유사 콘텐츠와 비교, 외부 편집자 블라인드 평가가 필요하다.

## 판정 게이트 (숫자는 내부 실험용, 시청률 보장 아님)
- **절대 불합격:** 사료에 없는 대화를 실제 대화로 표현; 감상 해석을 사실로 표현; 허위 인용/출처 누락; 고의적 감정 조작/허황된 위안; 유명 해설의 표절·무단 대량 발췌; 저작권/이용 조건 미확인 이미지.
- **G1: 우리가 읽는다.** 모든 문장을 거절 가능하도록 장면별로 직접 읽고, (1) 30초 안에 지적 긴장, (2) 단순 연대기 아닌 실제 갈등, (3) 인물이 선악 도식으로 납작해지지 않는가, (4) 지금 내 삶으로 역전하는 발견, (5) 과장 없이 진심이 남는 결말을 확인. 칭찬보다 이탈 지점의 타임코드·원인을 기록.
- **G2: 사실 분리:** FACT / VERIFIED_INTERPRETATION / CREATIVE_STAGING / UNSUPPORTED 표기. 인용은 근거 원문과 어휘를 비교. `UNSUPPORTED`가 있는 핵심 문장 1개라도 남으면 FAIL.
- **G3: 외부 독립 LLM 블라인드:** 동일 버전 원고, 출처팩, 소설적 장치 표지를 그대로 전달. ① 엄정한 편집자 ② 목표 연령 독자 대역 ③ 사료 검증 역할을 **분리**. 원고의 저자/의도/희망 점수를 숨기고 합격 강요 금지. 현재 호출 가능한 타사 LLM 연동 없음; NOT_RUN.
- **G4: 실제 사람 독서 시험:** 연령만으로 대표성 단정하지 않고 목표 정서적 경험을 가진 실제 독자 5~8인 (실행 전 동의), 원고 중단 구간·줄거리 이해·자기 삶과 연결된 대목·다시 볼 이유를 분리 조사. 연구 표본 규모가 작으므로 시장 수요 일반화 금지.
- **G5: 음성 검증:** 성우/TTS 실측 낭독 길이·숨·한자와 인명 발음·자막·정보 밀도 평가. 10~12분은 설계 목표이며 실제 러닝타임 NOT_VERIFIED.
- **최종 자체 합격:** 사람이 평가한 6개 축 (공감25/독창성20/구성20/사실15/음성10/여운10) 총 95/100 이상에 각 축 최소 9/10, 핵심 안전/진실 게이트 모두 PASS, 독립 LLM 평가의 구체적 중대 결함 미해결 0개, 실제 독서 시험에서 명백한 거부 반응이 없는 경우에만 '내부 출판 후보'. 95점 기준은 의도적으로 높은 내부 작업 목표일 뿐 보편 타당한 측정 도구는 아님.
- **반복 개선:** 각 라운드 편집본 버전 고정, 지적 결함 유형과 근거, 수정 후 전후 비교표 작성. 단순 재생성은 개선으로 간주하지 않음. 3라운드 내 핵심 원인 개선이 없으면 글짓기 기술 문제가 아니라 소재/프레임 재설계로 전환.

## 사실 근거와 쟁점
- 국립중앙박물관: https://www.museum.go.kr/MUSEUM/contents/M0501000000.do?relicRecommendId=623104&schM=view — 1844년 제주 제작, 위리안치, 이상적이 귀한 책을 보냄, 그림의 구성·갈필, 1845년 중국 문인 16명 찬시, 현 두루마리 1,469.5cm, 2020년 기증, **'장무상망' 인장 누가 찍었는지 불명**.
- 우리역사넷: https://contents.history.go.kr/mobile/kc/view.do?levelId=kc_r300670 — 『만학집』·『대운산방문고』·『황조경세문편』, 발문 속 권세에 대한 신랄함과 '전후 한결같음'의 뜻.
- 한국민족문화대백과: https://encykorea.aks.ac.kr/Article/E0038956 — 이상적의 귀한 책, 1844 답례, 북경 문인 기록.
- 과천 추사박물관 소개 페이지에는 '1843년 겨울'이라는 다른 연대 표기가 존재: https://www.gccity.go.kr/chusamuseum/ownRelic/view.do?idx=273&mId=0401000000 . **연대 불일치 존재**. 본 원고는 국립중앙박물관·우리역사넷이 사용하는 1844년을 따랐으며 날짜 논쟁을 단정하지 않음.
- 공공누리 3유형 표기의 박물관 설명문/영상 이미지 사용조건, 국가유산 실물 복제품 제작 제한과 상업적 영상 이미지 사용은 별도 라이선스 확인 전 사용 금지.

## 자체 비판 (저자 측)
1. 초반 '출세에 도움이 되는 집'은 발문의 권세 비판을 서사적으로 과장하는 편집 문구다. 실제로 모든 다른 수신인과 비교된 객관적 순위가 아니다.
2. 이상적의 동기를 문헌에서 직접 확인한 것은 아니므로 '왜 보냈나'의 답을 지위 계산이 없는 순수한 성정으로 단정해서는 안 됨.
3. '겨울이 오기 전부터 같은 나무가 된다'라는 결말은 감정적이지만 설교처럼 들릴 수 있다. 실제 목표 독자에게 어떻게 들리는지 블라인드 검증이 필요.
4. '인간의 삶' 투영이 보편적으로 공감된다는 보장은 없다. 독자 이탈 지점을 반드시 기록.
5. 원고 후반의 2020년 기증은 충실히 출처 검증했으나 영상 제작에서 실제 박물관 이미지의 사용권 분리 검증 필요.
