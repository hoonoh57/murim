# Murim Editorial Master Skill v2 — 제작 전에 작품을 먼저 완성한다

> 적용: 《명화로 이루어진 영화》, 《세한도》 등 **사료 기반 영화적 역사서사**. 기존 무협 전용 15비트/천마 세계관/고정 침묵·문장 길이 규칙은 이 장르의 절대 규칙으로 적용하지 않는다. 이 스킬은 G1·G2 제작 전 역할의 실행 계약이며 G3/G4 실물 품질 심사를 대신하지 않는다.

## NORTH STAR
시청자의 귀한 시간을 쓸 이유를 **첫 장면에서 행동으로 입증**한다. 휴식과 영화적 재미 속에서 새로운 사실과 인간의 선택을 발견하게 한다. 강요된 감동·교훈·추상적 신비·시청 유지 '해킹'·대중적 AI 템플릿은 금지한다. 작가가 아는 백 가지 중 관객이 몰입하는 데 필요한 것만 공개한다. 역사와 예술을 **사실을 손상하지 않는 서사**로 전달한다.

## 감독이 먼저 확정할 다섯 가지 (없으면 작가 집필 보류)
1. **관객 약속**: 누가, 왜 이 작품을 지금 끝까지 볼 것인가? 이미 있는 KBS/박물관 콘텐츠 대신 선택할 구체적인 경험은 무엇인가? 확인 전에는 차별성 '가설'.
2. **중심 사건/인간의 선택**: 누가 무엇을 얻거나 지키려 하고, 무엇이 막고, 어떤 행동의 결과로 상황이 달라지는가? 관객이 쫓는 실질적 질문 하나.
3. **사실의 경계**: 증거가 있는 사건·원전 인용·기관 해설·작가 해석·영상 재연·미상. 역사적 대화나 심리를 근거 없이 실제 사실처럼 만들지 않는다.
4. **원고 구조**: 막별 목표/전환/새 정보/다음 행동/끝에서 얻는 보상. 초반 0~30초와 결말을 먼저 고정. 중반 반복/설명 폭포/후반 설교를 제거한다.
5. **제작 현실**: 확보 가능한 진본·사용권·해상도·읽을 수 있는 실제 한국어 음성·화면 언어·재현 표시. '나중에 모델이 해결'은 제작안 아님.

## 제작 단계별 오너와 산출물
- **Director**: 작품 계약(관객 약속, 비교작, 고유 관점, 불변 사건, 금지사항, 범위, 끝의 보상)과 서사 승인 경계. 외부 LLM은 공동 감독이 아니다.
- **Research/Fact-check** (기존 Writer/Council 하위 책임): 주장별 1차 사료/원문/번역/날짜/맥락/이견/권리 및 미확인 원장. 팩트 없으면 HOLD.
- **Writer**: 6막 같은 작품 맞춤 선택 구조, 실제 읽히는 완결 원고, 막/장면마다 새로운 사건·결과. '개선해야 한다'가 아니라 고쳐 쓴 문장만 제출.
- **Story editor**: 처음 보는 사람이 30초 내 인물·시대·목적·장애를 이해하는지 무음악 소리 내어 읽기. 후반까지 매 막의 새 정보, 이해 혼란, 반복 표현과 정서 강요 역검토.
- **Art/Camera/Audio**: [문화·예술 시각 서사 스킬](CULTURAL_VISUAL_DRAMATURGY_SKILL_V1.md)을 적용. 반복 도판·원화의 노출 시간보다 각 쇼트의 **실제 시각적 발견·관객 시선의 이동·다른 시대 사건의 연결**을 감독. 실제 새 정보가 없는 재노출을 G2에서 REWORK하고, 원본 프레임 접촉시트/권리를 G3에서 별도 확인한다. 저해상도 반복과 기계음으로 줄거리 결함을 가리지 않는다.
- **Internal Council (adversarial)**: 원고의 모든 실패 지점을 증거 문장/장면/원인/수정 소유자/재검증 항목으로 작성. 모의 데이터와 점수 상승 예측은 승인 근거가 아니다.

## 절대 게이트
G0 연구/관객/비교작 계약 → G1 사실·문제설계 → G2 실제 전편 원고+무음악 낭독·내부 반대심사 → **사용자 최종 원고 확정** → G3 진본 자산/음성/짧은 실물 파일럿 → G4 최종 실제 작품·시청자 심사와 게시 승인.
- G0/G1/G2 미승인에는 어떤 이유로도 전체 GPU·TTS·영상 생성 착수 금지.
- 핵심 역사 오류, 미확인 권리, 주인공/시대/이유 혼란, 중간 반복, 결말 미완, 외부 재현을 사실로 오인시키는 연출은 **hard FAIL**. 출처/검증 자료가 없으면 **HOLD**. 평균점수로 상쇄 금지.
- 내부 95/100 및 축별 9점 목표는 **평가 증거를 해석하는 기준**이지 자동 완성 인증이 아니다. 자기 점수/모의 점수/비교작 미시청 점수로 'PASS' 금지.
- 같은 버전의 답변을 여러 번 받아 마음에 드는 점수만 선택 금지. 수정 전후 원문·비평·시청자 관측을 독립 보존.

## 외부 LLM 권한
독립 심사자는 **문제 제기/반증/근거 확인만** 한다. 작품 방향, 중심 관점, 시대 순서, 결말, 확정 인물·권리 범위를 통째로 뒤엎을 권한이 없다. 제안에는 문제 ID·실제 대본 문장·해당 출처·수정 범위·잠재 부작용을 명시; Director 승인 전 재집필 금지. 실제 문장 재작성 요청을 하더라도 승인된 **한 장면/한 문단** 범위로 제한. 외부 의견은 자동 진실도 자동 승인도 아니다.

## 고정되지 않은 것
장면당 글자 수, 반드시 15비트, 매 장면 3초 침묵, 무조건 어두운 조명, 장면 전부 Ken Burns, 출연 비율 등은 작품별 선택이다. 이를 품질의 대용 지표로 삼지 말 것.

## 검사 출력 규약
각 내부 반대심사 항목에는 `role, issue_id, severity, claim_or_scene, observed_excerpt, evidence_ref, why_viewer_leaves, required_change, owner, recheck, status`가 있다. 실증 전 `PASS` 불가. 보고는 관객에게 보이는 **원문 변화**와 해결 증거를 우선; 내부 스키마는 UI 기본 화면에 노출하지 않는다.
