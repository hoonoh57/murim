# Screenplay Master 전문 생산 상세 설계 심사 — v0.1

기준 2026-11-24 | DESIGN_HOLD | [전체 설계 게이트](../../../MURIM_PRECODE_DESIGN_GATE.md)
기존 SKILL.md v1은 후보 지침이다. 시나리오 생성 능력, 사람 대비 우위, 경쟁 앱 대비 우위가 입증되지 않았고 최종 스킬 변경/채택은 보류한다. 기존 G1/G2 및 역사/예술 사료 계약 유지.

## A. 핵심 설계 결함 및 보완 가설
1. 한 번 만든 줄거리/개요를 고정하고 장면을 순차 생성하면 전체 긴장/리듬/인과와 긴 문맥 유지가 실패할 수 있다. DOC/Re3의 계층화+현재 상태 재주입, DOME의 동적 개요, Storyteller의 narrative entity graph, StoryWriter의 사건 기반 계획/선택 기억을 비교한다. IS-CoT (2026 ACL)는 static planning 한계와 동적 plan-write-reflect를 다룬 학습 방법 후보, 즉시 채택 불가. 모두 원 연구 결과를 우리 각본 성능으로 외삽 금지.
2. 전문 스킬의 질적 규칙만으로 실제 창작 능력이 확보되지 않는다. 목적별 능력과 생성 모델 실측, 독창적 premise·갈등·인물 선택·결말의 서로 다른 창작 경로, 전체 arc와 장면 실물 비교가 필요하다. 동일 모델/프롬프트 표현만 바꾼 수십 개를 다양성으로 세지 않는다. 안전한 평균 원고로 수렴하지 않도록 작품 고유 목소리/위험한 창작 선택의 가치, 사용자 확정 의도, 장르 적합성, 새 발견, 실제 관객 반응을 검증.
3. 작가 역할과 심사 역할만 분리해도 독립 평가가 보장되지 않는다. CritiCS (2024 EMNLP)의 개요/본문 collective critique와 인간 협업 방식, Help Me Write a Story (2025 ACL) 및 Generating Constructive Feedback on Stories (2026 EMNLP Findings)의 feedback 연구를 비교한다. 생성·개선용 비평과 봉인된 최종 평가를 분리. LLM consensus는 인간 진실이 아니다.
4. 영화 각본은 일반 소설과 다르다. CML-Bench (2025 preprint, https://arxiv.org/abs/2510.06231)의 대사·인물·플롯 평가, STAGE (2026 preprint, https://arxiv.org/abs/2601.08510)의 장편 각본 entity/event/role 모델은 참고 후보. 실제 한국어 배우 낭독/시간/시각화 및 전문가 관점이 필요. 데이터 권리 및 대표성 검증 전 사용 금지.
5. 비용·시간 제한에서 후보의 창작 성능이 실용적으로 향상되는지 확인되지 않음. 일반 강한 LLM 단일 작성보다 반복 처리의 추가 비용이 가치 있는지 동일 예산과 동일 품질 실험을 각각 한다. 장르·길이별 baseline에서 이득이 없으면 구조를 축소/재설계/기존 전문 앱 채택.

## B. 제안된 생산 계약 (비코드, 후보)
- Project intent revision: 관객/작품의 약속, 관점·불변 사건/인물·권리, 장르/길이/목표, 사용자 자연어 수정의 승인/가역 가설 구분. 결정사항, 취향, 명시 금지사항을 원고와 결속한다. 임의 장르 규칙 추가 금지.
- Story state (Add-on private semantic model): 사건의 시간/순서 및 인과, 인물 욕망/관계/상태/각자가 알고 있는 정보, 설정/소품/장소, 장면별 변화와 관객이 아는 정보, 복선/회수/열린 질문, 승인된 사실/추정/재현, 주제·톤·시간 제약. 실제 원문 및 출처와 연결하고 소유권/갱신/충돌 해결, version pin. Core에 서사 의미 금지. summary/검색 컨텍스트는 원문 SSOT 대체 금지. 긴 문맥에서 필요한 상태+실제 문장+전체 arc가 정확히 전달되는지 검증.
- 후보 탐색: 여러 독립적 관점과 premise의 실제 짧은 treatment/핵심 장면을 생성하고 trade-off 분석. 전문 인간 작품과 장르 관례를 비교하되 표절/유사 문장·스타일 모방 목표 금지. 선택된 방향은 부모 목표로 잠금. 사용자 수정이 중요 방향을 변경할 때만 창작 승인.
- 동적 계층 작성: 작품→막/sequence→scene→beat. 사건·인물 선택→결과가 상태로 반영되며 다음 집필 입력을 갱신. 고정 계획은 불변 요구사항과 가역적 창작 계획 분리. 계층 계획과 집필이 상호 피드백하되 의존 DAG에 순환 실행을 만들지 않음(새 revision). 실패 영향 범위와 기존 승인 잠금. 장편 전체·단편·비선형 서로 다른 전문 전략.
- 실제 장면 작성 및 교차 검사: 인물 음성/대사, subtext, 선택/행동, 새 발견, 긴장/호흡, 실제 시각/음향 전환. 원고를 먼저 작성하고 실제 전체 낭독/시간·장면 연결 및 가능한 animatic으로 검증. 원고의 시각 구현 가능성이 미확인되면 제작 준비 HOLD, 미장센/장면 제약을 바꾸면 원고의 장점도 독립 재검증.
- 다층 수리: 비평은 defect/evidence/impact/repair boundary/counterfactual alternatives. 수정 전후 실물과 기존 성공 부분/미해결 사항을 확인. 통합 작품 평가에서 국소 최적화 퇴화 확인. 설계가 근본 결함이면 부모 단계로 되돌아가되 승인 의도를 보호. 반복 한계/품질 정체 시 전략/엔진 변경 가설 또는 HOLD.
- 생산 종료: 기존 작품 gate 승인 전 제작 금지. 최종 검증과 내부 편집에 동일 점수 반복 사용 금지. 실제 원고와 시청각 실현 가능성, 출처·권리 및 평가 evidence/불확실성 결속. 사용자에게는 실제 작품 및 중요한 창작 결정만 표시.

## C. 평가자 검증 선행
LitBench(EACL 2026) 범용 judge 최고 73% 일치는 인간 선호 예측의 제한을 보여주는 해당 실험 수치이며 한국어 screenplay 정확도 아님. 생성 평가용과 최종 독립 평가용 모델·rubric·예시를 분리. 권리 확인된 전문가/원어민 판단의 비교 사례와 명백한 결함 반례를 별도 구축. 정체 숨김, 제시 순서 교환, 문체/분량/출처 편향 및 동일 모델 계열 효과, 사람 간 불일치, 핵심 결함의 false acceptance, 근거 위치/원문 정확성, 반복 안정성, abstention 및 불확실성을 확인한다. 평가자 선정 기준/최소 수준/표본/판정 규칙은 파일럿으로 확정 후 holdout 이전 고정. 임의 95/100을 성공 증거로 부여하지 않음; 기존 작품 게이트의 수치 하한은 유지하되 타당한 평가 없으면 NOT_EVALUATED. 외부 LLM에는 칭찬 요청/자기 점수/기존 순위/스킬 이름을 제공하지 않고 실제 원고, brief, 권위 사료, 정규화된 비교 기준과 동일 관측을 제공. 평가는 서로 다른 취향을 보존하고 독창성을 다수결로 제거하지 않는다.

## D. 사전 코드 없는 실증 설계
권한 확보 후 기존 LLM/실제 경쟁 도구를 사용한다. 새로운 제품 실행기 개발 없이 실험 가능한 범위에서 진행하고 수동 실험 노력은 별도 기록. 생성군: 강한 단일 LLM + 기존 지침, 현행 Murim 스킬, 전문 상태/계층·대안/표적 수리 후보, 실제 Sudowrite/Novelcrafter 및 영상 제작 앱의 대응 가능한 각본 기능, 권리 확보 인간 전문 작가의 동등 brief 원고. 동등 조건이 아닌 유명 작품은 참고 앵커일 뿐 직접 승률 비교에 혼합 금지. 같은 모델 A/B와 완성 제품 E2E를 분리. 60–90초 무협/현대극, 수분 역사/예술, 장편 및 저대사/비선형을 포괄하는 fixture를 설계하고 실제 target segment를 정한다. 인간 작품 참여/사용권/동일 brief와 실제 비교 제품 사용 권한·비용 확보가 필요. 데이터와 결과를 만들기 전에 fixture·rubric·margin·표본 및 실험 예산을 고정하고 개발/검증/봉인 시험 분리. 실패 샘플 포함, 독립 블라인드 pairwise/tie 및 hard checks, 인간 전문가/타깃 관객 보정. 최소 품질/전문가 비열화 및 경쟁 대비 최소 의미 효과를 독립 평가 불확실성 포함 판정. 단기 실험의 통과를 장편/다른 장르/시장 전체의 우위로 확대 금지. 실제 생산 비용 및 사용자 조작(가설/수동 실험 조작 분리), 편집 재작업/권리/시간 기록.
Ablation: 동일 brief/모델/예산에서 state ledger, 동적 계획, 복수 대안, independent critique, 전문 skill, targeted repair를 하나씩 제거한 대조 실험. 실제 성능 이득이 입증되지 않은 복잡도는 제거하거나 대체한다. 스킬 개선자는 holdout에 접근 금지. 평가 비용이 과도하면 stage별 적합 평가기를 비교하되 최종 독립 시험을 약화하지 않는다.
시장 연결: 전문가 원고/경쟁 도구 대비 품질 및 사용자 노력 우위 → 실제 완성 영상에서 의도와 관객 반응 → 표적 고객의 반복 사용·자발적 유료 선택/경제성 관측. 각각 별도 증거. 외부 LLM 극찬을 시장 Alpha의 충분조건으로 삼지 않는다.

## E. 현재 설계 OK 여부
D0 경쟁 기능과 연구 조사 일부, D1 후보 연구(실제 채택/호환 미검증), D2 상세 생산 계약 초안, D3 평가 설계 초안, D4 NOT_RUN, D5 HOLD. 전문 한국어 원고/작가/관객, 경쟁 앱 실행, 실제 독립 LLM 평가, 표본/목표/예산 고정 및 결과 비교 미확보. 따라서 SKILL v1은 CANDIDATE_UNBENCHMARKED 유지. 본 파일을 제품 코드 개발의 승인서로 사용 금지.
