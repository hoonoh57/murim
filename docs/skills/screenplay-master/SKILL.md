# Murim Screenplay Master — 전문 시나리오 개발 스킬 v1

목표: 사용자의 말에서 작품 의도를 복원하고, 독창적이고 읽히며 제작 가능한 전체 원고를 자동으로 개발한다. 전문 지침을 근거로 개선하되 기관 인증/수상 가능성/시장 성공을 보장하지 않는다. 기존 역사/예술 전용 G1/G2 및 사료/권리 계약과 인간 승인 유지. 이 스킬은 실행 허가를 부여하지 않는다.

## 입력과 스킬 합성
- 프로젝트 brief, 목표 관객과 경험, 장르/매체/길이, 핵심 관점, 설정·확정된 인물/사건, 권한·비용·제작 제약, 기존 승인본, 사용자 수정의도.
- 불확실한 제작 기술은 내부 조사·선택. 사용자 의도 중 창작 방향을 좌우하는 상충사항만 쉬운 자연어로 확인. 비전문가에게 긴 설문이나 프롬프트를 요구하지 않는다. 나머지는 가역적 가설로 명시하여 실제 초안 제시.
- Manager에 장르·사료·캐릭터·대사·스토리·시각 설계·반대심사 capability를 요청할 전문 계획을 제공. 다른 Add-on 직접 호출 금지.
- 역사/예술이면 기존 EDITORIAL_MASTER_SKILL_V2 및 SOURCE_TRUTH_SKILL_V2, CINEMATIC_NARRATIVE_SKILL_V2, INTERNAL_RED_TEAM_SKILL_V2의 고유 계약 및 실제 자료 확인을 상속. 무협이면 해당 세계관·동작·인물 규칙을 선택. 현대/코미디/단편/비선형/다큐 등은 다른 구조 선택. 15비트나 장편 심사 양식을 보편 규칙으로 삼지 않는다.

## 집필 선행 전문 지식 (후보 계약, 미실증)
- [경쟁작 분석 라이브러리](../../MURIM_COMPETITIVE_WORKS_LIBRARY.md)의 장르/매체/관객별 Knowledge Pack을 Manager에 요청. 실제 관측된 비교작의 강·약·특이점/반례, 시장 언어, 인간 공명 및 적용 조건, 권리/근거/버전, 차별화 가설을 입력으로 사용한다. 검증된 지식 부족은 KNOWLEDGE_HOLD; 연구용 초안의 사전 실험은 가능하나 작품 승격 금지. 작품 자체의 표현/구체 사건/설정 복제 금지.
- 선택한 원리와 실제 원고에서의 독자적인 적용·효과/한계를 증거로 연결. 지식 pack의 적용 효과를 독립 작품·관객 비교로 확인. 현재 실제 pack 및 runtime 미구현, 스킬은 CANDIDATE_UNBENCHMARKED 유지.

## 부모-자식 집필 작업
1. **작품 계약:** 관객이 얻을 경험, 중심 사건 또는 주제, 주요 인물의 선택·제약, 결말의 보상, 금지사항, 제작 현실을 짧게 명문화. 필요한 조사/권리 검증을 먼저 수행하고 모르는 사실은 모른다고 기록.
2. **대안 탐색:** 구별되는 전제·관점·서사 구조를 전문적으로 검토하고, 관객 약속·독창성·제작 가능성 기준으로 장단점/근거를 비교. 기존 작품의 캐릭터/문장/구성을 복제하지 않는다. 사용자가 확정한 작품 방향은 임의로 바꾸지 않는다.
3. **구조:** 전체 시작-전개-결말 또는 선택한 비선형 구조가 관객에게 이해되는지 확인. 장면별 목적/행동/장애/새 변화/결과/관객의 새 발견과 필요한 시각·음향을 설계. 선택이 다음 사건에 영향을 주게 하고 편의적 해결이나 반복 설명을 검토. 역사에서는 사실에 없는 갈등이나 대화를 실제인 것처럼 발명하지 않는다.
4. **실제 원고:** 모든 장면의 행동·대사·필요한 시각/소리와 전환을 포함한 완결 원문을 생성. 인물의 음성·말투·목적·관계 일관성, 영화적 행동, 불필요한 설명, 자연스러운 한국어를 점검. 줄거리 요약/기획서/수정 의견만으로 완성 원고를 대체하지 않는다.
5. **독립 검수:** 독립 전문 평가자에게 원고·brief·권위 사료·rubric 제공, 생성자 자기 점수와 기존 평가 점수 숨김. 아래 축을 평가하고 실제 문장/장면과 이유·영향·수정 경계를 적는다. 해당 매체의 실제 낭독/읽기 시간·시각화 가능성을 관측. 증거가 없으면 NOT_EVALUATED. 생성자가 자신의 산출물을 최종 승인하지 못한다.
6. **표적 개선:** 중대 결함부터 원인 자식/장면/문단을 수정, 이전 좋은 부분과 사용자 확정 사항 보존, 새 immutable revision에서 해당 결함 및 전체 영향을 재검증. 실제 변경 문장과 전후 독립 관측을 기록. 목표 미달이면 허용 범위 내 다른 작성/편집 전략을 시도; 예산/진척 한계 도달 시 HOLD. 점수 하향 조작/강제 GO 금지.
7. **부모 통합:** 모든 필수 child 및 통합 rubric 통과, 실제 전체 원문과 증거 결속 후 기존 사용자 감수 경로에 전달. 기술적 PASS와 작품성 PASS는 분리. G1/G2 승인 전 실제 제작 금지.

## 전문 rubric의 공통 축
- 독창적인 전제와 작가적 관점: 익숙한 소재라도 새 경험/관찰을 제공하는가.
- 서사·인과·이해: 선택과 결과가 일관되며 장르에 맞는 시작/전개/마무리가 작동하는가.
- 인물과 대사: 개별 목소리, 동기, 관계와 변화(작품에 적합한 경우), 한국어 자연스러움.
- 극작·시각적 전달: 장면의 기능, 행동, 긴장/유머/정서, 시각·음향의 기여.
- 관객 가치와 여운: 실제 사건/발견/감정/사유가 독서·시청 시간을 정당화하는가.
- 사실·권리·제작 가능성: 적용 장르의 별도 hard checks; 임의 사실, 사료 왜곡, 미확인 권리, 확정 의도 위반은 평균으로 상쇄하지 않는다.
평가 척도 및 목표는 Manager가 적용할 별도 버전 계약과 fixture에 사전 고정한다. 기존 G1/G2 기준은 유지. 이 스킬은 심사 점수를 자체 발급하지 않는다. 전문 출처와 적용 한계는 [professional sources](references/professional-sources.md), 실증은 [benchmark protocol](references/benchmark-protocol.md) 참조.

## 자연어 교류와 품질 에스컬레이션
사용자가 "두 번째 장면의 긴장감이 약해"라고 하면 단순히 어둡게 바꾸거나 수식어를 늘리지 않는다. 해당 장면의 인과/위험/기대/선택을 진단, 수정 가설 비교, 실제 새 원고 생성, 국소 및 전체 독립 검수, 이전 좋은 부분 보존. 사용자에게 변경된 실제 원고와 중요한 결과만 쉬운 말로 보여 준다. 다음 질문은 창작 의도를 결정하는 데 필요한 경우로 제한. 자연어 피드백은 프로젝트 revision에 귀속하며 전역 스킬 학습의 자동 권한은 아님.

## 출력
실제 전체 원고, 장면 지도, 작품 계약·사용자 결정, 입력/스킬/원고/검토 revision 및 해시 참조, 독립 평가 근거, 결함/개선/재검증 증거, unresolved/HOLD 이유, 제작 현실과 사료/권리 부록. 내부 데이터는 기계검증 탭 소비 계약으로 제공. 사용자가 원고를 요청했을 때 검사표를 원고인 것처럼 전달하지 않는다.
