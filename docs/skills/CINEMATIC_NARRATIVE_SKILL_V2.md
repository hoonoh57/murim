# Murim Cinematic Narrative Skill v2 — 설명보다 사건, 감동 강요보다 발견

## 구조 (장르별 선택, 획일 공식 금지)
- 관객이 따라갈 사람·현재 상황·원하는 것·장애·이번 장면에서 변하는 것을 **한 문장**으로 말할 수 있어야 한다.
- 첫 0~3초: 인물/사물/행동의 구체적인 사건, 익숙한 'AI 영상'과 구별되는 실제 원작의 존재. 0~30초 안에 제목이 약속한 첫 보상을 보여 준다. 구독/훈계/세계관 요약으로 시작하지 않는다.
- 각 막: 이전보다 중요한 **새 증거·새 선택·새 결과** 중 하나가 반드시 등장한다. 장면이 없다면 관객이 무엇을 놓칠지 확인; 없어도 이해되면 압축 또는 삭제.
- 시간 점프: 장소/시대/새 인물을 최소한의 자연어로 다시 기준점 잡는다. 시대 전환을 음악·색감만으로 처리 금지.
- 중반: 이미 안 사실을 이름만 바꿔 재설명하지 않는다. 앞 사건을 다시 조명할 다른 증거/제약을 보여준다.
- 결말: 초반의 핵심 질문에 사건과 관객이 직접 판단할 여지로 응답한다. 인생의 교훈을 직접 설교하거나 '우리 모두' 감정 동일시 강요 금지.
- 길이: 25~40분 등은 **가설**. 낭독/실물 컷 검증 후 결정. 3초 침묵·고정 음절/문장 규칙을 절대화하지 않는다.

## 세한도 서사 구조 보증점
V0.2 프롤로그(1944 손재형이 반환을 구함)의 국소 좋은 독서 경험을 유지하되 전체 2~5막은 별도 구조 검증. 시간축과 선택의 주체가 흔들리면 편집을 멈춘다. 1844 스승·제자와 1944 소장자·반환자가 '그림을 간직/건네는 서로 다른 이유'로 연결된다는 사건성을 유지. 미확인 사적 대화·마음의 동기 창작 금지. 마지막 2020 기증과 긴 두루마리의 잔존 여백은 확정 사실과 해석의 경계를 지키는 결말 후보; 반복 여운으로 길이를 채우지 않는다.

## 내부 독자 4명 관점
1. 배경지식 0인 시청자: 지금 등장한 사람이 누구이고 왜 움직이는지?
2. 시간이 아까운 시청자: 다음 30초에 볼 이유가 실제 사건으로 있는가?
3. 역사·예술에 익숙한 사람: 사료/연대/원작 오인 없이 진실한가?
4. 감정 강요를 싫어하는 사람: '의미가 있다'고 설교하지 않고 선택·행동을 보여주는가?

## 원고 리뷰 루프
실제 60~90초 무음악 낭독 → 막 전체의 비트/정보 변화 지도 → 후반까지 낭독 → 부족한 특정 문단을 **실제 고쳐 씀** → 같은 조건 재청취. '더 영화적으로' 같은 의견만 생산하지 않음. 읽는 길이와 발화 속도는 실측값 사용. 시각 효과나 BGM을 추가해서 원고 혼란을 감추지 않음.

## 출력
- 감독 약속 1문장, 중심 질문 1문장, 등장인물과 이해에 필요한 맥락.
- 막/장면별 `goal / obstacle / observed_change / evidence / viewer_reward / next_question` 지도.
- **최종 전체 대본 원문**과 내부 자료 검증 부록을 분리. 결함 메모는 사용자에게 원고인 척 전달 금지.
