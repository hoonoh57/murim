# Murim Source Truth Skill v2 — 사료보다 그럴듯한 장면을 우선하지 않는다

## 연구자/Writer 필수 입력
- 사료 묶음: 원전 URL·기관/소장번호·원문 인용 위치·판본·번역자·접근일·저작권/이미지 사용권·원본 이미지 바이트/해시(획득했을 때).
- 하나의 문장마다 주장 ID를 연결하고 `FACT / DOCUMENTED_INTERPRETATION / DRAMATIZED_STAGING / UNKNOWN` 중 하나로 구분한다.
- 주요 연대기는 사건일, 사료 작성일, 재현 화면의 배경일, 사진/도판 제작일을 분리한다. **1842 간찰을 1844 장면 증거**로 사용하는 식의 혼동을 hard FAIL.
- 같은 사건에 복수 권위 자료가 다르면 한쪽을 임의 선택하지 말고 문장 강도를 낮추고 충돌·판본 차이를 명시한다. 후지쓰카 설득 기간 같은 상충 기록은 정량 단정 금지.
- 사료에 없는 심리·현장 대화·인장 제작자·장면 동작은 **작가의 상상**으로 표시하거나 폐기. '그는 반드시 ~했을 것' 식의 감정 단정 금지.
- 원작의 서화/인장/한문 원문은 AI 생성 비슷한 회화로 바꿀 수 없다. 별도 창작 재연 컷은 '재현' 분명히 식별; 역사 지도의 최신 지명도 구분.

## 구체적 감사 질문
1. 이 말은 누가/언제/어디서 확인했는가? 최초 원전과 2차 설명을 구분했는가?
2. 영상 화면이 본문의 사실을 **증명하는 그림처럼** 오해시키지 않는가?
3. 사건 순서와 인과를 너무 단정하지 않았는가?
4. 예상 시청자가 모르는 김정희·이상적·후지쓰카·손재형 관계를 필요한 시점에 이해할 수 있는가?
5. 근거 불충분한 주장을 뺐을 때도 사건이 살아 있는가?
6. KBS/박물관/언론의 장면·문장 구성을 모방하지 않고 자체 사건/관점이 있는가?

## 세한도 알려진 주의
- 1944 손재형/후지쓰카, 1844 제주 추사/이상적, 1845 문인 제찬, 1949 발문, 2020 기증은 서로 다른 시대. 출처 확인 전 구체 대사·장면을 실제 기록으로 표기 금지.
- '장무상망' 인장 주체는 불명이라는 박물관 기술을 따름. 미스터리 정답 창작 금지.
- 공식 출발점: 국립중앙박물관 소장품 증10000, 관련 간찰 기록; `docs/SEHANDO_EDITORIAL_GATE.md` 및 `docs/CONTENT_COMPETITIVE_PRODUCTION_STRATEGY_V1.md`의 기존 검증 URL. 링크의 존재와 실물 자산 바이트 확보/사용 허가는 독립 확인.
- 1944 현장 사진·대화, 1844 책의 실제 도착일, 원본 종이의 한자·인장 확대 해상도 등이 미검증이면 미검증이라고 서술.

## 전달물
`claim_id / exact_script_excerpt / event_date / source_date / source_url / primary_or_secondary / direct_quote_or_paraphrase / confidence / portrayal_policy / rights / reviewer / resolution`.
자료가 없으면 `NOT_EVIDENCED`; Writer가 감추지 않고 대본을 수정한다. 낭독용 본문과 사실 검증 메모는 구분해 보관한다.
