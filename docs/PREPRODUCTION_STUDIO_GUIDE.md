# Murim Studio — 원문 비교·확정

1. 기존 작품을 열고 00A에서 왼쪽에 표시된 실제 원본을 확인합니다. 원본은 최초 M-VML에서 읽은 기존 대본·장면 제작정보이며 기록되지 않은 기획을 지어내지 않습니다.
2. 원문 재작성 요청 복사를 눌러 외부 LLM에 전달합니다. 요청은 개선 의견·설명·점수·JSON이 아닌 수정된 전체 원문만 요구합니다. 감독의 자연어 추가 지시는 선택 사항입니다. 기존 비평은 참고로 포함되며 반복 입력하지 않습니다.
3. 오른쪽에 외부 LLM이 반환한 수정 원문을 그대로 붙여넣고 수정 원문 저장. 텍스트/Markdown 그대로 저장하며 제작 데이터 형식 검증 없음. 이전 전달 실패 답변이 보존된 경우 가져올 수 있습니다.
4. 원문과 수정본 비교 후 최종 원문 편집란에 원하는 내용을 직접 조합·수정합니다. 수정본 전체 또는 기준 원문 전체 사용 버튼도 있습니다. 최종 원문 확정 저장을 누르면 사용자 편집 내용 그대로 프로젝트에 새로운 버전으로 보존됩니다.
5. 00B에서 원본 및 확정본을 선택해 비교하고 복사할 수 있습니다. 확정 원문은 다음 수정 작업의 기준으로 선택 가능합니다.

## 실제 제작을 시작할 때만
00C에서 확정 원문을 내부 M-VML 제작 데이터에 연결하는 별도의 외부 AI 요청을 사용합니다. 확정 원문 자체를 다시 작성하는 과정이 아닙니다. 서버는 문서 리비전과 실제 발화·자막이 원문에 포함되는지 검사하며, 장면 순서·의미·누락은 독립 심사를 통해 검증합니다. 기존 비평 전체, 결함 및 확정 원문과 연결 결과를 심사합니다. 기존 95점/각9/미해결0/인간 최종 제작 승인 조건 유지. 문서 확정만으로 제작이 승인되지 않습니다. AI 직접 API 호출은 미연결이며 인간 매개 복사/붙여넣기를 사용합니다. 원문 비교/확정 단계에는 제작 연결 형식이 필요 없습니다.

프로젝트별 원본·후보·확정본·제작안·독립 평가 이력은 기존 해시 연결 ledger에 보존됩니다. 새 원문을 확정하면 기존 제작 승인 잠금. 이전 실패작 및 미디어는 그대로 보존됩니다.
