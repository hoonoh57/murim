# Murim Studio — 자연어 중심 사전 제작 사용법

기획·시나리오가 검증되기 전에는 실제 제작할 수 없다. 사용자 역할은 감독이며 내부 제작 데이터 분류·작성은 AI가 수행한다.

## 사용 순서

1. **00A 개선 지시**: 기존 Gemini 비평 전체를 붙여 넣고 비평 원문 저장. 일반 문장·Markdown 표 그대로 입력 가능. 문제를 사용자가 별도 항목으로 나누거나 JSON을 편집하지 않는다. 새 작품이고 이전 비평이 없으면 생략 가능.
2. 감독의 자연어 지시를 입력하고 '수정 요청 복사'. 기존 비평 전체를 해결하도록 요청할 경우 지시 생략 가능. ChatGPT/Gemini 수정 담당 세션에 전달하면 AI가 수정 원문·전체 실제 대본과 프로그램용 데이터를 함께 작성한다. 답변 전체를 붙여넣으면 자동 수신하며 유효한 수정본은 전후 비교로 이동한다. 수동 '답변 반영 및 전후 비교' 버튼도 제공한다. 일반 비평을 수정 답변으로 잘못 입력하거나 전달 블록/필수 내용이 누락되면 응답 원문을 프로젝트에 별도 보존하고 정확한 미반영 이유를 표시한다. '누락 항목 보완 요청 복사'로 AI에게 보완을 요청한다. 직접 형식을 고칠 필요가 없다.
3. **00B 원문·수정본 비교**: 기본은 V0 원본과 현재 수정본. 이전 버전 선택도 가능. 실제 발화 대본 전체를 읽고 변경된 기획과 장면의 수정 전후 텍스트를 비교한다. AI의 변경 설명은 독립 심사 전 주장이다. 추가 지시가 있으면 00A에서 반복.
4. **00C 재심사·승인**: 독립 재심사 요청을 복사해 수정 담당 AI와 별도 세션에 전달. 원본·수정본·기존 비평 전체와 결함 목록이 포함된다. 반환된 전체 답변을 심사 모델·세션과 함께 등록. 사전 편집 6축 점수와 개별 문제 해결 증거 확인. 95점 이상·각 9점 이상·미해결 0·미평가 없음 및 명시 사용자 승인 전 제작 잠금. 예상 점수는 실제 심사가 아니다. 재심사 불합격이면 00A에서 구체적 재수정. 동일 버전 점수 재입력 불가.
5. '검토 완료 · 이 수정본으로 제작 승인' 후 기존 6단계 실제 제작. 이전 실패 결과물은 읽기 전용 보존. 기획/대본 구조 변경은 사전 제작으로 반환. 최종 실제 영상은 기존 VIEWER_VALUE_GATE_V1 10축 별도 심사.

## 이력 및 경계
프로젝트별 불변 해시 연결 제작안과 원문, 원래·수정 버전, AI 수정 응답 전체·감독 지시 및 독립 비평/개별 재검증 결과를 보존한다. 기본 화면은 읽기 쉬운 실제 대본 비교와 자연어 지시이며 내부 형식은 복사되는 요청에만 포함된다. 인간 매개 작업으로 직접 API 호출이나 독립 응답의 진위를 자동 보증하지 않는다. 원문 비평에서 빠진 문제가 없는지 독립 재심사에서도 전체 원문을 검토한다. 실제 수정본과 심사 증거가 없는 정리 응답은 합격할 수 없다.
