# Murim Studio — M-VML 60초 인트로 실증 (v0.1)

이 패키지는 독립적인 평가용 저작도구입니다. 기존 Murim 애플리케이션 또는 ComfyUI 설치를 변경하지 않습니다. **완성본이 아니라 회화형 애니매틱 기준점**입니다.

## 실행
- Python 3.9 이상, Pillow, FFmpeg 및 ffprobe, 한글 폰트가 필요합니다. Windows에서는 `start-intro-lab.cmd`를 실행한 뒤 브라우저에서 `http://127.0.0.1:8769`를 여십시오. 실행기에서 라이브러리를 자동 설치하지 않습니다. Windows 환경은 이 대화에서 검증하지 못했습니다.
- 다른 운영체제에서는 이 폴더에서 `python intro_lab.py`를 실행합니다. 필요 시 환경변수 `MURIM_FONT`를 로컬 한글 폰트 절대경로로 설정하십시오.
- 첫 화면에서 이미지 및 카메라 ID, 컷 지속시간, 제목·자막을 수정하고 컴파일합니다. 합계는 정확히 60초여야 합니다. 렌더 버튼은 FFmpeg에서 새 MP4를 만들어 재생 주소를 반환합니다. 저장 버튼은 편집한 XML을 다운로드합니다. 원본을 덮어쓰지 않습니다. `Ctrl+C`로 로컬 서버를 종료합니다.
- `python intro_lab.py --compile`은 파일 해시와 ID를 검사, `python intro_lab.py --render`는 실제 렌더, `python -m unittest test_intro_lab`은 컴파일 8개 시험을 수행합니다.

## 패키지와 소스 경계
- `intro.mvml.xml` (편집 가능한 원본), `intro_lab.py` (컴파일/로컬 렌더/HTTP), `studio.html` (저작 UI), `test_intro_lab.py`, 시작 CMD.
- `assets/`에는 ChatGPT로 생성한 6개의 회화 시안이 들어 있습니다. GitHub에는 미디어 원본을 올리지 않습니다. 저장소에서 받은 코드로 실행할 경우 이 평가 패키지의 **assets/만** 동일 상대경로에 복사해야 합니다. 원본/사용자 파일 덮어쓰기 금지. 패키지 ZIP에는 입력 미디어와 샘플 MP4를 모두 포함합니다.
- `sample.json`, `renders/.../intro.mp4`는 이번 실측 평가본을 UI에서 재생하기 위한 결과입니다. 새 실행의 결과는 매번 별도 폴더로 생성합니다.

## 평가 경계
- 8컷, 60.000초, 1280×720, 24fps, 1440프레임, H.264 + AAC. 실제 FFmpeg CPU 렌더 및 ffprobe 확인.
- 실제 컴파일러는 typed ID, 버전 형식, 해시, 경로, 컷 지속시간과 카메라를 해석합니다. 스타일·주제·인물 ID는 등록/검증만 하며 모델 조건화나 동일인 검증은 아직 하지 않습니다. 전체 XML 대신 씬별 반복 프롬프트가 없어도 등록 이미지가 렌더에 직접 들어갑니다.
- 생성된 이미지들은 역사적 진본이나 실제 초상이 아닙니다. 1944년 회화는 장소·시대의 분위기 시안이며, 세한도 모티브 회화는 진본이 아닙니다. 6개 이미지는 동일한 원본 생성 시트에서 분리했고 일부를 크롭했습니다. 원본 초고 v0.2는 보존했습니다. 진본 확보와 사료/복식 감수는 미완료입니다.
- 음성 트랙은 외부 음원 없는 임시 합성 배경음이며 한국어 내레이션 없음. 독립 관객의 평가, ComfyUI 실제 GPU 영상 생성, 동일 인물의 각도별 생성, 외부 제작 도구 전환은 NOT_RUN.
- 격리 컨테이너에서 실제 HTTP 컴파일, 400/403 차단, 이미지 조회, 렌더 및 MP4 응답을 확인. JavaScript 문법 검사 PASS. Chromium GUI 자동 접속은 ERR_BLOCKED_BY_ADMINISTRATOR로 중단되어 **실제 브라우저 WYSIWYG NOT_VERIFIED**. Windows에서도 별도 확인 필요. 현재 코드의 선택/편집 기능을 완전히 실증했다고 선언하지 않습니다.
- 수익화/게시/자동 외부 서비스 호출은 하지 않습니다. 이 영상은 시각과 호흡을 평가하는 비교용 데이터입니다.
